# Innovation Lab Project Management

This repository contains the Innovation Lab planning website for team operations, governance, and project execution.

## What This Project Includes

- `index.html` - Main hub (links to all site pages)
- `innovation_lab_handbook.html` - Operations handbook, workflow, accountability, and policy guidance
- `agrichain.html` - AgriChain team plan, member assignments, approvals flow, and master timeline
- `new.html` - AgriChain intern weekly progress report (Firebase)
- `dashboard-full.html` - Full submissions dashboard showing each intern’s complete entries
- `stars-supabase.html` - STARS project documentation (plain language + technical)
- `stars-submit.html` - STARS integration story submissions (Firebase)
- `css/` · `js/` - Shared styles and scripts (paths are lowercase for Vercel/Linux)

Every page includes the top **Innovation Lab** nav bar (`js/site-nav.js`) linking Hub, Handbook, AgriChain, STARS Docs, STARS Submit, and Progress Report.

## Quick Start

1. Open `index.html` in your browser.
2. Click:
   - `Handbook` for operating standards and policies
   - `Project` for team assignments and execution timeline

## Current Operating Model

- Command chain is governed by Operations.
- Teams must run feasibility discussions and present outcomes to Operations before major implementation.
- Technology stacks listed are recommended, not compulsory (alternatives allowed with approval).
- Cross-team collaboration is required for shared APIs, security, infrastructure, and deployment.

## Timeline Note

- Timeline planning is aligned to working days (Monday to Friday).
- Kickoff begins on `06 May 2026` with project brief, role clearance, and research setup.
